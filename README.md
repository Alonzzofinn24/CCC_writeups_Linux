# CTF Writeups — Linux & Digital Forensics

Repositorio dedicado a la documentación y análisis de retos CTF
enfocados principalmente en la gestión, administración y seguridad
de sistemas Linux, así como en forense digital.

## 🎯 Objetivos

- Documentar la resolución de retos CTF.
- Practicar la administración y seguridad de sistemas Linux.
- Comprender permisos, propietarios y grupos.
- Analizar SUID, SGID y sudo.
- Practicar técnicas relacionadas con SSH.
- Desarrollar habilidades de análisis forense digital.
- Trabajar con archivos PCAP y tráfico de red.

## 📚 Categorías

### 🐧 Linux

Retos relacionados con la administración y seguridad de sistemas Linux.

Temas:

- Permisos
- Propietarios y grupos
- SUID y SGID
- sudo
- SSH
- Escalada de privilegios

### 🔎 Forense Digital

Retos relacionados con el análisis e investigación de evidencias digitales.

Temas:

- PCAP
- Wireshark
- tcpdump
- Análisis de tráfico de red
- Extracción de información
- Investigación de evidencias

## 🧪 Plataformas

- PicoCTF

- Otras plataformas de CTF
